This document summarizes the converted LIF-SNN model for ship/no_ship satellite 
image classification and provides the key implementation details required for FPGA/ASIC-oriented 
hardware development.

===========================================================================================================

SUMMARY OF MODEL:

Base ANN: MobileNetV4-Conv-S
Task: Binary satellite image classification
Classes: no_ship / ship
Input size: 224 × 224 × 3
Output classes: 2
Conversion type: ANN-to-SNN conversion
Neuron type: LIF
Readout: Output LIF spike count
Best timestep: T = 192

T=128 also gives very good results.

===========================================================================================================

FINAL SNN CONFIGURATION:

checkpoint_path = "aug_80k_best_mobilenetv4_ship_classifier.pth"

The final selected model uses the 80k ANN checkpoint with channel-wise thresholds calibrated
using the 30k calibration set. This is a cross-calibrated SNN setup.
The final classifier output is also converted to LIF spike-count readout, so the decision is made by
comparing output spike counts.

===========================================================================================================

ANN to SNN CONVERSION DETAILS:

Original ANN block:
Conv → BatchNorm → ReLU

Converted SNN block:
FusedConv → LIF

Conv layers keep the learned spatial filters.
BatchNorm is folded into Conv for hardware-friendly inference.
ReLU activations are replaced with LIF neurons.
The final output is converted into class spike counts using Output LIF neurons.

===========================================================================================================

LIF NEURON DYNAMICS:

At each timestep:
1. Input current is received from previous Conv/Linear layer.
2. Membrane potential decays by decay factor.
3. New input is integrated.
4. If membrane >= threshold, spike is generated.
5. Membrane is reset by subtraction.

===========================================================================================================

THRESHOLD INFORMATION:

The final model uses channel-wise thresholds instead of a single scalar threshold per layer.
Each output channel has its own threshold value with shape [1, C, 1, 1].

| Threshold type | Shape          | Meaning                       |
| -------------- | -------------- | ----------------------------- |
| Layer-wise     | scalar         | One threshold for whole layer |
| Channel-wise   | `[1, C, 1, 1]` | One threshold per channel     |

===========================================================================================

BN FOLDING:

BatchNorm is not implemented as a separate hardware block. Instead, BatchNorm parameters are folded into 
the preceding Conv weights and bias.

scale = gamma / sqrt(var + eps)

W_fused = W * scale
b_fused = beta + (b - mean) * scale

===========================================================================================

CROSS-CALIBRATION:

The best SNN configuration was obtained using a cross-calibrated setup. The ANN weights were taken from
the augmented 80k checkpoint, while the activation thresholds were calibrated using the 30k calibration data.

This shows that the best ANN checkpoint and the best SNN threshold calibration source do not necessarily
have to be the same.

===========================================================================================

HARDWARE IMPLEMENTATION NOTES:

1. Conv layers are not fully connected.
2. Depthwise Conv should be implemented separately from pointwise Conv.
3. LIF state memory is required for each activation tensor.
4. Channel-wise thresholds require per-channel threshold storage.
5. BN is folded into Conv, so no separate BN hardware block is required.
6. Output decision is based on spike count over T timesteps.
7. Selected T is 192 for latency/accuracy balance.
8. Subtraction reset is used after spike generation.
